# Ninebot Suspension Pro v4.2 Suspension Lab

## 功能
- Ninebot 风格三种车辆侧视图：越野 / 踏板 / 街跑
- 前后减震精细热点点击
- 扩展减震调校范围
- 前后弹簧、预载、LSC、HSC、LSR、HSR、K1、K2
- 完整车辆档案
- 轴距、转向角、拖曳距 Trail
- 前后轮胎尺寸与胎压
- Free SAG / Rider SAG
- 实时平衡评分
- 调校历史记录
- Canvas 趋势图
- 本地自动保存
- Online + Offline PWA
- GitHub Pages Ready

## 文件
index.html
style.css
app.js
manifest.json
service-worker.js

## GitHub Pages
上传全部文件到仓库根目录，然后：
Settings → Pages → Deploy from branch → main → /(root)

首次在线打开后，Service Worker 会缓存核心文件。之后在同一浏览器中可离线打开。
