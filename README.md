# Ninebot Suspension Pro v4.3 — Pro Geometry & Spring Calculator

## v4.3 核心升级
- 根据骑手体重 + 车辆重量自动计算总载荷
- 前后重量分配参与前后弹簧推荐
- 根据前后悬挂行程与目标 SAG 计算推荐弹簧刚度
- 支持前后悬挂杠杆比
- 自动计算推荐前后预载
- 一键应用推荐 Setup
- 前叉倾角 + Trail 几何参数保留
- 前后 K1 / K2 独立调节保留
- 在线 + 离线 PWA

## 全局范围规则
所有可调节的减震参数滑块统一使用：
- 最小值：0
- 最大值：300

包括：
- 前后弹簧刚度
- 前后预载
- LSC / HSC
- LSR / HSR
- 前后 K1 / K2

> 推荐值超过 300 时自动限制为 300。
