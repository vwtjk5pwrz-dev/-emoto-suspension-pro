# Ninebot Suspension Pro v4.0

## 文件说明
- index.html：主页面
- style.css：专业深色工业风界面
- app.js：SAG 自动计算、前后平衡、诊断、记录、本地保存、导出
- manifest.json：PWA 配置
- service-worker.js：基础离线缓存

## GitHub Pages 部署
1. 新建 GitHub 仓库。
2. 上传全部文件到仓库根目录。
3. 打开 Settings → Pages。
4. Source 选择 Deploy from a branch。
5. Branch 选择 main，Folder 选择 /(root)。
6. 保存，等待 GitHub Pages 生成网址。

## iPhone / iPad
使用 Safari 打开 GitHub Pages 网站后，可选择“添加到主屏幕”，作为网页 App 使用。
